EXECUTIVE SUMMARY

Project MEKA is a revolutionary, decentralized AI assistant ecosystem engineered to bridge the gap between artificial intelligence and physical IoT hardware. Unlike cloud-locked smart speakers, MEKA operates across 7 independent pillars—running on your phone, desktop, web browser, and ESP32 hardware chassis seamlessly with zero cloud lock-in and a sub-50ms state synchronization engine.

CORE ARCHITECTURAL PILLARS

1. FUTURE (AI) HUB
Python Flask brain server. Manages mDNS/ARP discovery, dynamic hardware fallback hierarchy, camera transcoding, and LLM intent parsing.
2. PHYSICAL HARDWARE
ESP32-WROOM-32D chassis. Non-blocking C++ firmware with I2C LCD matrix scrolling, servo pan/tilt, and optional I2S audio modules.
3. CYBERPUNK WEBAPP
React 18 + Vite command center. Real-time telemetry, camera streaming, and device permission management from any modern web browser.
4. FLUTTER MOBILE APP
Cross-platform Android companion. Always-on background wake word engine ("MEKA"), voice transcription, and native biometric lock.

DYNAMIC HARDWARE FALLBACK ENGINE PATENT-PENDING LOGIC

NATURAL LANGUAGE VOICE COMMAND MATRIX

Natural spoken commands are parsed by LLM intent processing into structured JSON payloads executed on physical hardware.

USER SPOKEN VOICE COMMAND SYSTEM INTENT PARSED EXECUTED HARDWARE / API ACTION
"Scan the network for new devices" iot_scan Triggers ARP / mDNS broadcast scan across LAN
"Show me all connected cameras" iot_list_cameras Fetches camera registry & updates dashboard stream grid
"Start recording all security cameras" iot_record Initiates background MP4 recording on server storage
"Take a snapshot of the front door" iot_snapshot Captures high-res JPEG frame from specified camera ID
"Switch microphone to my phone" iot_select_mic Overrides fallback hierarchy & routes audio to mobile app
"Turn on the yellow LED" esp32_led Mutates Firebase state: led/yellow = true (50ms)
"Pan camera 90 degrees to the right" esp32_servo Sends PWM signal to GPIO 18 servo motor

CROSS-PLATFORM CLIENT ECOSYSTEM

WebRTC-powered web bridge. Instantly converts any old smartphone into a camera, microphone, and speaker node without installing an app.
